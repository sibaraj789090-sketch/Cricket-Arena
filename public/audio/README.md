# Hindi Background Music Asset Guide

Place your original or royalty-free Hindi instrumental background music file here:

**Target File Path**:
`/public/audio/hindi_ludo_bgm.mp3`

### Format Recommendations:
- Format: MP3 or M4A/AAC or OGG
- Genre: Indian Classical / Folk / Festive instrumental (Sitar, Flute, Shehnai, Tabla)
- Duration: 1 to 3 minutes loopable
- Bitrate: 96kbps - 128kbps (recommended for fast mobile loading)
- License: Royalty-free / CC0 / Original composition (no copyrighted Bollywood tracks)

### Fallback Mechanism:
If no audio file is uploaded at `/audio/hindi_ludo_bgm.mp3`, Cricket Arena's built-in Web Audio procedural Indian folk synthesizer automatically provides cheerful festive background music without any missing file errors. Once `hindi_ludo_bgm.mp3` is uploaded, it is automatically detected and played.
